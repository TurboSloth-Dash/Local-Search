# START HERE - iPad directions

This app is meant to feel simple.

You do **not** need to know Python.
You do **not** need to buy a server.
You do **not** need a paid AI account.

Think of it like this:

- GitHub = a free box that holds the app files.
- Streamlit Community Cloud = a free computer that runs the app.
- Safari = the screen you use.
- Library of Congress = one of the free historical newspaper libraries.

## Put the app online

1. Download `gulf_south_research_ai_v6.zip`.
2. Tap the ZIP in the iPad Files app. The iPad will unzip it.
3. Make a free GitHub account.
4. Make a new GitHub repository named `gulf-south-history`.
5. Upload these three files:
   - `streamlit_app.py`
   - `research_core.py`
   - `reports.py`
6. Also upload `requirements.txt`.
7. Go to `share.streamlit.io`.
8. Sign in with GitHub.
9. Tap **Create app**.
10. Pick your `gulf-south-history` repository.
11. Choose `streamlit_app.py`.
12. Tap **Deploy**.
13. Wait for the app website to appear.
14. Open it in Safari.
15. Tap Safari **Share** > **Add to Home Screen**.

Now it acts almost like an app icon.


## Research subject / reference number

There is now a simple field called **Research subject / reference number**.

Use anything that will help you recognize the case later.

Examples:

- `Tiger Cigars`
- `Hernsheim Research`
- `CASE-2026-014`
- `Covington Depot`
- `Smith Family 1890-1920`

This reference is saved with the case and appears in the PDF, Excel workbook, and file names when possible.

You do not have to use a formal case-number system. It is just a label for future reference.

# How to use it

## Search

Type what you want to know.

Example:

`Who manufactured Tiger Cigars in New Orleans around 1890-1910?`

Then add:
- the main person/business/place if you know it
- location
- years
- Quick, Standard, or Deep

Tap **START RESEARCH**.

The app handles spelling variations, old abbreviations, OCR mistakes, and relevant newspaper choices in the background.

## Follow clues

A result may contain a new:
- person
- business
- address
- organization
- contract/project number

Tap **Follow clues**.

The app only shows the strongest next clues instead of throwing every word at you.

## Explore

Use **Explore** when you do not know exactly what you are looking for.

Example:

Place: `Covington`
Years: `1880-1910`
Topic: `Businesses`

Tap **DISCOVER FORGOTTEN HISTORY**.

## Case

Save useful findings.

The Case page tells you:
- how much evidence you have
- important research gaps
- which source types make sense next

Download the case backup JSON when you are finished for the day.

That JSON file is your research notebook.

## Evidence

Choose a saved finding.

You can:
- open the original source
- mark it Verified, Corroborated, Probable, Possible, or Lead
- inspect extracted people/businesses/addresses
- correct OCR only when needed

## Reports

### PDF
Tap **Create / Download PDF**.

On iPad:
1. Open the PDF.
2. Tap the square-with-arrow Share button.
3. Choose Mail, Save to Files, AirDrop, Print, or another app.

### Excel
Tap **Create / Download Excel**.

The first tab is always Overview.
Other tabs only appear when the results make them useful.

## Advanced

Ignore this unless you need it.

It contains:
- source map
- newspaper list
- search log
- negative searches
- research rules

# The most important rule

The app helps **find** evidence.

The original newspaper page, government record, census record, deed, photograph, or archival document is the evidence.
